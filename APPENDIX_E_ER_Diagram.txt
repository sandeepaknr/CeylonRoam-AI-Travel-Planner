SECTION 4: DATA FLOW — USER BOOKING LIFECYCLE
================================================================================

  [User] ──> Browses /api/packages (GET)
          ──> Views package /api/packages/:id (GET, increments views)
          ──> Creates booking /api/bookings (POST)
                → Booking.status = "Pending"
          ──> Initiates payment /api/payments/create-order (POST)
                → PayPal Order created (status: CREATED)
          ──> Approves in PayPal UI (@paypal/react-paypal-js)
          ──> Captures payment /api/payments/capture-order (POST)
                → Payment document saved (status: Completed)
                → Booking.status updated → "Confirmed"
          ──> Seller sees booking via /api/seller-bookings/all
          ──> Seller updates /api/seller-bookings/update/:id
                → Booking.status → "Completed"
          ──> User posts review /api/reviews (POST)
